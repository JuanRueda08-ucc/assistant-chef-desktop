# Chef digital

Asistente culinario de escritorio para Windows, macOS y Linux. Eliges lo que tienes en la cocina, indicas porciones, restricciones y tiempo, eliges una receta y un chef animado te guía paso a paso con voz, temporizadores y control por voz, sin tener que tocar la pantalla con las manos sucias.

**Estado:** base del proyecto y modelo de datos definidos; la app aún no está implementada. Ver [docs/estado.md](docs/estado.md).

- Documentación: [docs/README.md](docs/README.md)
- Instrucciones para agentes de código: [AGENTS.md](AGENTS.md) (Codex) y [CLAUDE.md](CLAUDE.md) (Claude Code)

Stack: Electron, Svelte + TypeScript + Vite, SQLite, IA por API con herramientas, voz en tiempo real, avatar Rive.
